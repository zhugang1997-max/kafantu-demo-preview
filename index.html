Demo notes

a storefront study.

This is a static concept demo built to test layout, typography, merchandising and the purchase flow. It is not a production store.

Real in this demo

  • Page routing, hover mega menu, search, filters and sorting
  • Product pages, ratings, sample reviews, size selection, quick add and cart
  • Checkout validation, demo order and email preview
  • Policies, FAQ, contact form and mobile navigation

Simulated

  • Payment — no card is collected or charged
  • Order email — preview only, not sent
  • Stock, tax, shipping rules and analytics
  • Review content and review form — sample copy, not stored
  • Newsletter, contact and account forms

Data. Cart and demo orders live in this browser's localStorage. Clearing site data removes them. Please use fictional details only.

Reviews. Ratings, review counts and review cards are sample content for design preview. They are not customer feedback and must be replaced by verified reviews before launch.

Materials. Brand, products, copy and placeholder photography are original or licensed stand-ins. No Rhode imagery, copy, logo, font files or theme code are used. Do not publish this demo as a live store.

Production. The real build will use WordPress + WooCommerce, real products, Stripe/PayPal, order email, tax and shipping rules, and the brand's own photography and licensed fonts.
